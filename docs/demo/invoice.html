The current code calculates the start index as `page * per_page`, which for page=1 results in `start=4` (when per_page=4), causing the slice to begin at index 4 and return [4,5,6,7]. This is incorrect because page is 1-based, so page 1 should start at index 0. The fix is to adjust the start index to `(page - 1) * per_page`, which will correctly return the first page as [0,1,2,3].
